### 终端 0：预检并选定新目录

先完整运行本终端并把输出留存/回传；只有全部通过后才启动仿真。lsof +D 对整个旧 bag 目录递归检查，涵盖 .db3 与 SQLite sidecar。lsof 若对目标目录报错或检查结果不明，也停止，不把“看起来没有 PID”当作无占用证明。

~~~bash
set -uo pipefail
source /opt/ros/humble/setup.bash || { echo 'STOP: ROS 2 环境加载失败'; exit 1; }
source "$HOME/mobile_robot_delivery/install/setup.bash" || { echo 'STOP: 项目工作区环境加载失败'; exit 1; }
cd "$HOME/mobile_robot_delivery" || { echo 'STOP: 项目目录不存在'; exit 1; }

acceptance_root="$HOME/mobile_robot_delivery_acceptance_logs"
trial="$acceptance_root/D3-a_2026-10-29_capture_probe_002"
preflight_log="$acceptance_root/D3-a_2026-10-29_capture_probe_002_preflight.log"
if [ -e "$trial" ] || [ -e "$preflight_log" ]; then
  printf 'STOP: preserve existing attempt; increment number: %s or %s\n' "$trial" "$preflight_log"
  exit 1
fi
exec > >(tee "$preflight_log") 2>&1

for tool in ros2 lsof python3; do
  command -v "$tool" || { echo "STOP: 缺少工具 $tool"; exit 1; }
done
python3 -c 'import sqlite3, rosbag2_py; print("sqlite3", sqlite3.sqlite_version, "rosbag2_py", rosbag2_py.__file__)' || {
  echo 'STOP: Python SQLite 或 rosbag2_py 不可用'; exit 1;
}
printf 'ROS_DISTRO=%s ROS_DOMAIN_ID=%s\n' "$(printenv ROS_DISTRO || true)" "$(printenv ROS_DOMAIN_ID || true)"
printf '%s\n' '=== processes that would conflict ==='
conflicts="$(ps -eo pid=,ppid=,comm=,args= | awk '
  $3 ~ /^(gzserver|gzclient|rviz2|planner_server|controller_server|amcl|map_server|rosbag2_recorder)$/ ||
  ($3 == "ros2" && ($5 == "launch" || ($5 == "bag" && $6 == "record"))) ||
  ($3 ~ /^(python3|python)$/ && $0 ~ /delivery_task_server/) { print }
'")"
printf '%s\n' "$conflicts"
if [ -n "$conflicts" ]; then echo 'STOP: 有遗留仿真/导航/录制/任务进程'; exit 1; fi
printf '%s\n' '=== live ROS nodes ==='
nodes="$(ros2 node list)" || { echo 'STOP: ROS graph 查询失败'; exit 1; }
printf '%s\n' "$nodes"
if [ -n "$nodes" ]; then echo 'STOP: ROS graph 中有遗留节点'; exit 1; fi
printf '%s\n' '=== old bag directories and open handles ==='
find "$acceptance_root" -type d \( -name bag -o -name '*probe_bag' \) -print
while IFS= read -r -d '' bagdir; do
  printf '\n--- lsof: %s ---\n' "$bagdir"
  lsof_report="$(lsof -nP +D "$bagdir" 2>&1)"
  lsof_rc=$?
  printf '%s\n' "$lsof_report"
  if [ "$lsof_rc" -gt 1 ]; then echo 'STOP: lsof 无法确认旧 bag 占用'; exit 1; fi
  if printf '%s\n' "$lsof_report" | awk '$1 == "COMMAND" { header=1; next } header && NF { found=1 } END { exit !found }'; then
    echo 'STOP: 旧 bag 目录存在打开句柄'; exit 1
  fi
done < <(find "$acceptance_root" -type d \( -name bag -o -name '*probe_bag' \) -print0)
printf '%s\n' '=== existing SQLite DB and sidecar files ==='
find "$acceptance_root" -type f -name '*.db3*' -printf '%p %s bytes\n' | sort

if [ -e "$trial" ]; then
  printf 'STOP: preserve existing directory and increment attempt number: %s\n' "$trial"
  exit 1
fi

~~~
人工检查点：进程列表和 ros2 node list 都没有遗留仿真/Nav2/recorder/task server；旧 bag 的 lsof 没有文件句柄数据行（仅与目标无关的系统文件系统 warning 可记录后说明）；工具导入成功；目标目录不存在。若任一失败，停在这里，不建目录、不启动。
