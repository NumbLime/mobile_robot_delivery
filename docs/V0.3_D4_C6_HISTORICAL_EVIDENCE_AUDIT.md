# V0.3 D4 历史 C6 证据边界审计（8 分部分；2026-11-03）

本次只读核对仓库外 `~/mobile_robot_delivery_acceptance_logs/C6_2026-10-28/run_001/` 的原始 bag、首次删除响应、模型列表、运行参数日志与既有 `C6_RUN_001_OFFLINE_ANALYSIS.md`，并对照 [PROJECT_STATUS.md 的历史 C7 记录](PROJECT_STATUS.md)。未启动仿真、调用服务或修改原始证据。D4 新实验 12 分已另见[来源分析](V0.3_D4_NEW_COST_SOURCE_ANALYSIS.md)；本审计**不**以新实验未复现异常来认定 C6 已修复，也不重计 V0.2 的 C6/C7 分数。

## 原始数据和复核方法

- `bag/metadata.yaml` 与 `bag/bag_0.db3` 存在。SQLite 以只读模式打开，`PRAGMA integrity_check=ok`；metadata 与 SQL 均为 **454,906** 条、17 个话题。原始 `/global_costmap/costmap` **326** 张、`/local_costmap/costmap` **1,464** 张、`/scan` **4,857** 条、`/gazebo/model_states` **24,285** 条、`/plan` **45** 条。bag **没有 `/map`**、单独图层栅格、清图服务请求事件或服务客户端调用追踪。
- Unix 时间只用于服务命令、bag 接收与无 header 的 Gazebo `ModelStates` 近邻配对；地图、扫描、TF 和 `/clock` 的仿真 header 另行读取，不把两种时间直接相减。全局地图的 frame 一直为 `map`、origin `(-2.93,-2.95)`、分辨率约 0.05 m、尺寸 117×118；固定格 `(70,30)` 对应中心约 map `(0.595,-1.425)`，与当轮报告的箱体 map 估计中心 `(0.571,-1.427)` 接近。局部地图是 `odom` 滚动窗口，以下局部格由近时刻 Gazebo 机器人 world 位姿和 `odom→base_footprint` TF 把箱体 world 位置换入 `odom`，每张按自身 origin/resolution 查询；Gazebo 模型消息无仿真 header，配对只属近时刻估计。
- `global_plugins.log` 记录实际插件 `[static_layer, obstacle_layer, inflation_layer]`，`global_scan_topic.log` 为 `/scan`，`global_radius.log` 为 0.55 m；项目 [navigation.yaml](../src/delivery_robot_bringup/config/navigation.yaml) 还配置扫描 marking/clearing。运行记录没有每个图层的单独栅格或该轮逐项 marking/clearing 参数回读，配置不能代替内部状态记录。

## 来源与跨轮边界

箱体已从 Gazebo 真值中消失，所选扫描扇区回到远距，局部对应区域清为 0，而全局邻域只部分清除、余下 82 个高代价格保持至 bag 末。这将问题限定为**本轮全局合成 costmap 的残留现象**，但不能唯一定位到全局障碍层的观测缓存、膨胀层对残留标记的传播、静态层输入、地图叠加、清图服务时序或其他内部状态。bag 未录 `/map` 与单独图层，也没有清图服务调用事件；控制台没有可用的逐格层状态。`/scan` 某个方向的回波消失也不等于全局障碍层每个旧标记都已接受清除射线。

另一次仓库外 `C5_2026-10-26/planning_run_002/C5_A_055_OFFLINE_ANALYSIS.md` 记录了箱体删除后全局格清为 0；早期 C4 报告记录的是**不同配置下的局部**清除。它们证明清除行为并非每轮都相同，**不能覆盖 C6 的原始残留**。V0.3 D3-c/D5 的新实验也出现正常清除，但未记录全体清图服务客户端调用，不能据此断言历史异常原因已消失。

**结论：**完成冻结 D4 历史 C6 的有依据证据审计，计 **8/8**；与已完成的新实验分析 12/12 合计 D4 **20/20**。这里的“完成”指现象、时间边界、已有对照和缺口交代完整，**不表示 C6 残留来源已查明或问题已修复**。最终消退时间仍未知；早期超时运行约 0.15 rad 持续同向 odom 偏航也未解。仓库外原始 bag、日志未随 GitHub 仓库备份。
